# 제작 계획

> 작성: 2026-11-02 · 대상: Routine Calendar (`com.kikilog.routinecalendar`)

## 한 줄 목표

"이불 세탁 2개월마다 · 모델링팩 1주마다 · 각질제거 10일마다 · 화장지 구매 2달 후" 를 **딱 한 번 등록하면**, 월 캘린더에서 언제 해야 하는지 보이고, 했으면 체크한다.

## 범위

**만드는 것**: 루틴 등록 · 완료일 기준 다음 날짜 계산 · 오늘 할 일 · 월 캘린더(예정 + 체크) · 하루 1회 알림 · 홈 화면 위젯 · JSON 백업

**하지 않을 것**: 계정 · 동기화 · 서버 · 가족 공유 · 점수/게임 요소 · 할 일 목록 · 습관 통계 · 가계부 · 시간 단위 알람 · 광고

## 1. 화면

하단 탭 3개(오늘 · 캘린더 · 루틴) + 오른쪽 위 설정.

```text
┌ 오늘 ──────────────────────┐   ┌ 캘린더 ─────────────────────┐
│ 11월 2일 (월)               │   │ ◀  2026년 11월  ▶           │
│ ── 지난 것 ──               │   │ 일 월 화 수 목 금 토          │
│ ☐ 각질제거       3일 지남    │   │     2● 3  4  5● 6  7          │
│ ── 오늘 ──                  │   │  8  9✓10 11 12● 13 14        │
│ ☐ 모델링팩                   │   │ ...                         │
│ ☐ 화장실 청소                │   │ ── 11월 9일 ──               │
│ ── 이번 주 ──               │   │ ✓ 모델링팩                   │
│   이불 세탁   11/6 (금)      │   │ ☐ 화장실 청소                │
└───────────── [+] ──────────┘   └─────────────────────────────┘
```

| 화면 | 하는 일 | 핵심 동작 |
|---|---|---|
| **오늘** (첫 화면) | 지난 것 · 오늘 · 이번 주 예정 | 체크 한 번으로 완료. "N일 지남" 표시. [+] 로 등록 |
| **캘린더** | 월 단위로 예정(●)과 완료(✓) 표시 | 날짜를 누르면 아래에 그날 목록. 지난 날짜에서도 체크 가능(실제로 한 날 기록) |
| **루틴** | 등록한 루틴 전체 | 이름 · 주기 · 마지막으로 한 날 · 다음 예정일. 누르면 수정, 길게 눌러 보관/삭제 |
| **루틴 등록/수정** | 한 화면짜리 양식 | 프리셋 고르기 → 이름 · 분류 · 주기(숫자 + 일/주/개월) · 반복 여부 · 마지막으로 한 날(선택) · 알림 켜기 |
| **설정** | 앱 전체 설정 | 알림 시각(기본 오전 9시) · 주 시작 요일 · 백업 내보내기/가져오기 · 개인정보 안내 · 앱 버전 |
| **위젯** | 홈 화면 | 오늘 + 지난 것 목록, 바로 체크. 누르면 앱의 오늘 화면 |

**프리셋** (등록 화면의 빠른 선택, 값은 고칠 수 있음)

| 분류 | 프리셋 |
|---|---|
| 집안일 | 청소기 1주 · 빨래 1주 · 화장실 청소 2주 · 이불 세탁 2개월 · 세탁조 청소 1개월 · 냉장고 정리 1개월 · 분리수거 1주 |
| 뷰티 | 모델링팩 1주 · 젤팩 1주 · 각질제거 10일 · 리들샷 (주기 직접 입력) |
| 구매 | 화장지 2개월 · 세제 2개월 · 칫솔 교체 3개월 (반복 없는 "N 후 한 번" 도 가능) |

## 2. 데이터 구조

### 저장하는 것 (Room)

**`routine`**

| 열 | 타입 | 설명 |
|---|---|---|
| `id` | Long PK | 자동 증가 |
| `title` | String | "이불 세탁" |
| `category` | enum | `HOUSE` · `BEAUTY` · `SUPPLY` · `ETC` |
| `interval_amount` | Int (≥1) | 2 |
| `interval_unit` | enum | `DAY` · `WEEK` · `MONTH` |
| `repeats` | Boolean | false 면 한 번만 ("화장지 2달 후") |
| `first_due` | LocalDate | 처음 할 날 (아래 규칙) |
| `notify` | Boolean | 알림 요약에 넣을지 |
| `archived` | Boolean | 보관(숨김). 기록은 남김 |
| `created_at` | Instant | |

**`completion`**

| 열 | 타입 | 설명 |
|---|---|---|
| `id` | Long PK | |
| `routine_id` | Long FK | `routine.id`, 루틴 삭제 시 함께 삭제 |
| `done_on` | LocalDate | 실제로 한 날 |
| `created_at` | Instant | |

`(routine_id, done_on)` 유일 — 같은 날 두 번 체크 안 됨.

**설정 (DataStore)**: `notify_time` (기본 09:00) · `week_start` (기본 일요일)

### 계산하는 것 (`:core`, 저장하지 않음)

다음 예정일은 저장하지 않고 매번 계산한다. 저장하면 체크/취소 때마다 맞춰 줘야 해서 틀리기 쉽다.

```text
다음 예정일 = 완료 기록이 있으면  마지막 done_on + 주기
             없으면              first_due
반복 없음(repeats=false) + 완료 기록 있음 → 끝남 (예정 없음)
```

- **완료일 기준**: 각질제거를 예정보다 2일 늦게 했으면 다음 예정도 그날부터 10일 뒤. 일찍 해도 마찬가지
- **등록할 때 `first_due`**: "마지막으로 한 날" 을 넣으면 그날을 완료 기록으로 저장하고 `first_due = 그날 + 주기`. 비우면 `first_due = 오늘` (반복 없음이면 `오늘 + 주기`)
- **개월 더하기**: 1월 31일 + 1개월 = 2월 28일(29일). `kotlinx-datetime` 의 `plus(DatePeriod)` 동작을 시험으로 고정
- **지난 것**: 다음 예정일 < 오늘 → "N일 지남"
- **캘린더 예정 표시**: 다음 예정일부터 주기씩 더해 그 달 끝까지 펼친다(미래는 추정치). 지난 달은 완료 기록만 보인다
- **체크 취소**: 그 완료 기록을 지우면 다음 예정일이 자동으로 다시 계산된다

### 모듈 · 패키지

```text
:core   (순수 Kotlin/JVM — android.* 금지, 나중에 KMP commonMain 으로)
  model/        Routine, Completion, Interval, Category
  schedule/     nextDue(), occurrencesIn(month), overdueDays()
  preset/       기본 프리셋 목록
:app    (Android)
  data/         Room 엔티티 · DAO · RoutineRepository · DataStore
  ui/today/  ui/calendar/  ui/routines/  ui/edit/  ui/settings/  ui/theme/
  notify/       WorkManager 작업 · 알림 채널
  widget/       Glance 위젯
  backup/       JSON 내보내기/가져오기
  AppContainer.kt   수동 의존성 묶음
```

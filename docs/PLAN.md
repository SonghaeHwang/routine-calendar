# 제작 계획

> 작성: 2026-11-02 · 대상: Routine Calendar (`com.kikilog.routinecalendar`)

## 한 줄 목표

"이불 세탁 2개월마다 · 모델링팩 1주마다 · 각질제거 10일마다 · 화장지 구매 2달 후" 를 **딱 한 번 등록하면**, 월 캘린더에서 언제 해야 하는지 보이고, 했으면 체크한다.

## 범위

**만드는 것**: 루틴 등록 · 완료일 기준 다음 날짜 계산 · 오늘 할 일 · 월 캘린더(예정 + 체크) · 하루 1회 알림 · 홈 화면 위젯 · JSON 백업

**하지 않을 것**: 계정 · 동기화 · 서버 · 가족 공유 · 점수/게임 요소 · 할 일 목록 · 습관 통계 · 가계부 · 시간 단위 알람 · 광고

## 1. 화면

하단 탭 2개(달력 · 루틴) + 오른쪽 위 설정. 오늘 탭은 2026-11-03 사용자 요청으로 숨겼다(코드는 남겨 두어 다시 살릴 수 있음, `VISIBLE_TABS`). 아래 그림은 처음 계획 — 지금은 달력 칸에 분류 색 점이 보인다.

```text
┌ 오늘 ──────────────────────┐   ┌ 캘린더 ─────────────────────┐
│ 11월 2일 (월)               │   │ ◀  2026년 11월  ▶           │
│ ── 지난 것 ──               │   │ 일 월 화 수 목 금 토          │
│ ☐ 각질제거       3일 지남    │   │     2● 3  4  5● 6  7          │
│ ── 오늘 ──                  │   │  8  9✓10 11 12● 13 14        │
│ ☐ 모델링팩                   │   │ ...                         │
│ ☐ 화장실 청소                │   │ ── 11월 9일 ──               │
│ ── 이번 주 ──               │   │ ✓ 모델링팩                   │
│   이불 세탁   11/6 (금)      │   │ ☐ 화장실 청소                │
└───────────── [+] ──────────┘   └─────────────────────────────┘
```

| 화면 | 하는 일 | 핵심 동작 |
|---|---|---|
| **오늘** (숨김, 2026-11-03) | 지난 것 · 오늘 · 다가오는 7일 예정 | 체크 한 번으로 완료. "N일 지남" 표시. [+] 로 등록 |
| **달력** (첫 화면, 「캘린더」에서 이름 변경) | 월 단위로 분류 색 점(예정) · 같은 색 ✓(완료) · 빨간 테두리(놓침) | 좌우로 밀어 달 이동. 날짜를 누르면 아래에 그날 목록. 지난 날짜에서도 체크 가능. 꾹 누르면 루틴 정보. 「알림 켤까요?」 카드 |
| **루틴** | 등록한 루틴 전체 | 분류 색 점 · 이름 · 주기 · 마지막으로 한 날 · 다음 예정일. 누르면 루틴 정보, 길게 눌러 선택(삭제 · 보관) |
| **루틴 정보** | 읽기 전용 | 분류 · 주기 · 반복 · 알림 · 다음 예정일 · 마지막으로 한 날 · 앞으로 예정일 3개 · 등록일. 아래 「편집하기」 |
| **루틴 등록/수정** | 한 화면짜리 양식 | 프리셋 고르기 → 이름 · 분류(색 칩 + 분류 편집) · 주기(숫자 + 일/주/개월) · 반복 여부 · 루틴 시작일(기본 오늘, 앞날 가능) · 알림 켜기 |
| **설정** | 앱 전체 설정 | 알림 켜기 · 시각(기본 오전 8시, 30분 단위) · 주 시작 요일 · 첫 화면(달력 · 루틴) · 분류 편집 · 빠른 선택 편집(꾹 눌러 끌어 분류 옮기기) · 백업 내보내기/가져오기 · 개인정보 안내 · 앱 버전 |
| **분류 편집** | 설정 · 등록 화면에서 | 추가 · 이름 · 색(계열 9개 × 5단계, 처음에는 자동) · 삭제(든 항목은 기타로, 기타는 지울 수 없음) |
| **위젯** | 홈 화면 | 오늘 + 지난 것 목록, 바로 체크. 누르면 앱의 달력 |

**설정 (DataStore)**: `week_start` (기본 일요일) · `start_screen` (기본 달력) · `notify_enabled` (기본 꺼짐) · `notify_time` (기본 08:00) · `last_notified_on` · `notify_card_dismissed`

### 계산하는 것 (`:core`, 저장하지 않음)

다음 예정일은 저장하지 않고 매번 계산한다. 저장하면 체크/취소 때마다 맞춰 줘야 해서 틀리기 쉽다.

```text
다음 예정일 = 완료 기록이 있으면  마지막 done_on + 주기
             없으면              first_due
반복 없음(repeats=false) + 완료 기록 있음 → 끝남 (예정 없음)
```

- **완료일 기준**: 각질제거를 예정보다 2일 늦게 했으면 다음 예정도 그날부터 10일 뒤. 일찍 해도 마찬가지
- **등록할 때 `first_due`** ("루틴 시작일", 2026-11-03 변경, `startSchedule`): 오늘 · 앞날이면 `first_due = 시작일`(기록 없음). 지난 날이면 예전 "마지막으로 한 날" 과 같다 — `first_due = 그날 + 주기`, 반복하는 루틴만 그날을 완료 기록으로 저장(반복 없음에 저장하면 등록하자마자 끝남)
- **개월 더하기**: 1월 31일 + 1개월 = 2월 28일(29일). `kotlinx-datetime` 의 `plus(DatePeriod)` 동작을 시험으로 고정
- **지난 것**: 다음 예정일 < 오늘 → "N일 지남"
- **캘린더 예정 표시**: 다음 예정일부터 주기씩 더해 그 달 끝까지 펼친다(미래는 추정치). 지난 달은 완료 기록만 보인다
- **체크 취소**: 그 완료 기록을 지우면 다음 예정일이 자동으로 다시 계산된다

### 모듈 · 패키지

```text
:core   (순수 Kotlin/JVM — android.* 금지, 나중에 KMP commonMain 으로)
```
